## Current initiative

- **Configurator CWU/AIO gating:** AIO recommendation now follows Panasonic K-series pairing more strictly. If CWU demand is above 200 l, step 1 no longer recommends 185 l all-in-one units (`KIT-ADC03/05/07/09K3E5`, `KIT-ADC09/12/16K9E8`). A 260 l AIO is shown only when the selected split family has an explicit Panasonic large-CWU AIO pair (`aio_model_large_cwu`), so lower-power split families stay split-only with a freestanding tank instead of being forced into a 260 l fridge. ## Canonical truths to preserve

- `kalk-top` is the TOP-INSTAL decision core.
- The canonical system boundary remains `CalcRequestDTO -> POST /wp-json/topinstal/v1/calculate-offer -> OfferDTO`.
- `top-instal-generator` is a downstream rendering/output tool, not a business-decision authority.
- Future AI channels, agents, and AI OS ideas must remain adapters or orchestration around the decision core, not replacements for it.

## Known active risks

- Static schema drift risk is narrower now: local `kalk-top` request/offer schema copies were aligned to runtime `schemaVersion = "1.0"`, but copied generator-facing schema artifacts still require explicit verification or continued demotion to reference-only status.
