# ADR Template

## Title

Short decision title.

## Status

Proposed | Accepted | Rejected | Superseded

## Context

- What problem is being solved
- Which subsystem owns it
- Which contracts, runtime paths, or integrations it touches

## Decision

State the chosen approach clearly.

## Why

- Main decision drivers
- What tradeoffs were accepted

## Change surface

- affected layers
- affected contracts
- affected runtime paths
- affected downstream repos

## Verification

- plan mode review
- tests or harnesses
- browser or debug evidence

## Rollback

- flags
- config-only rollback options
- safe reversal path
