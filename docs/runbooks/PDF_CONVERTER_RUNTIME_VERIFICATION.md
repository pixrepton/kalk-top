# PDF Converter Runtime Verification

Verification sources:
- `gmail-agent/test-results/runtime_audit_results.json`
- `test-results/pdf_runtime_validation.json`
- downloaded files in `test-results/pdf_runtime_samples/`

## Runtime setup used

- Generator endpoint: `POST /wp-json/topinstal/v1/offer-documents/generate`
- Converter URL configured in WP option:
  - `top_instal_pdf_converter_url = http://127.0.0.1:8091/forms/libreoffice/convert`
- Converter token configured:
  - `top_instal_pdf_converter_token = runtime-converter-token`
- Converter service used for test:
  - local API-compatible mock: `core/infrastructure/agents/test_station/mock_pdf_converter.py`

Reason:
- no external Gotenberg/LibreOffice service was available on this machine (`docker`/`soffice` not present), so the nearest practical runtime equivalent was used.

## Tested scenarios (real runtime)

Input path for all scenarios:
1. Call `calculate-offer` (agent key auth) -> get full `OfferDTO`
2. Call `offer-documents/generate` with `mode=from-offer-dto`, `outputFormat=pdf`
3. Download returned `document.downloadUrl`
4. Validate binary PDF signature and parse with Python PDF reader (`pypdf`/`PyPDF2`)

- runtime conversion path produced valid, readable PDFs in all 3 tested cases.

## Source DOCX and request path

- Request path: `POST /wp-json/topinstal/v1/offer-documents/generate`
- Mode: `from-offer-dto`
- Output format: `pdf`
- DOCX source files are generated by `TopInstal_GenerateOfferDocument_UseCase` before conversion in the plugin upload directory `wp-content/uploads/top-instal-offers/`.

## Manual deploy settings for production

1. Set real converter URL in `top_instal_pdf_converter_url`.
2. Set real converter token in `top_instal_pdf_converter_token`.
3. Keep `top_instal_agent_api_key` set for agent auth to generator REST.
4. Run one smoke call `offer-documents/generate` with `outputFormat=pdf` and verify returned PDF URL opens.
