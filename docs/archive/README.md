# Documentation Archive

This folder contains historical or migration-era documentation that is kept for audit value, not for day-to-day operation.

## Why these files were moved

The active `docs/` tree should describe the current runtime and current contracts. Older reports and transition notes were making the live documentation harder to trust because they described:

- pre-extraction Gmail runtime ownership
- historical runtime matrices and E2E reports
- migration execution snapshots
- compatibility verification for legacy paths that are no longer part of the main runtime story

## Archived sets

### Migration history

- `migration/ADAPTER_MIGRATION_EXECUTION.md`

### Compatibility history

- `compatibility/LEGACY_COMPATIBILITY_VERIFICATION.md`

Use these files as historical evidence only. For current guidance, return to the active docs map in `docs/README.md`.
