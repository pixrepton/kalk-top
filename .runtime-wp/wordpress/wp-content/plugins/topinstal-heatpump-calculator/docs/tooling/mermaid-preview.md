# Mermaid Preview

Mermaid preview guidance is documentation, not an always-on Cursor rule.

## Recommended VS Code extensions

- `bierner.markdown-mermaid` - renders Mermaid blocks inside standard Markdown preview
- `vstirbu.vscode-mermaid-preview` - dedicated Mermaid preview panel

## How to preview diagrams

1. Open a Markdown file containing a Mermaid block.
2. Use Markdown preview: `Ctrl+Shift+V` on Windows/Linux or `Cmd+Shift+V` on Mac.
3. Or right click the file and choose `Markdown: Open Preview`.

## Common diagram files

- `MODULE_DIAGRAM.md` - architecture, flow, and dependency diagrams
