# FIELD_MAPPING.md

## Scope
- Mapping from legacy generator form/AJAX payload to new `OfferDocumentRequestDTO`.
- Source form: `generator.js` (`data` sent to `action=simple_generate`).
- Target DTO consumed by `GenerateOfferDocumentUseCase`.

## 1) Top-level mapping (legacy -> DTO)

### `schemaVersion`
- Constant: `"1.0"`.

### `traceId`
- Source priority:
  1. incoming payload `traceId` (if present),
  2. generated by `topinstal_ensure_trace_id()`.

### `mode`
- Legacy path: always `direct-config`.
- New supported mode: `from-offer-dto` (for agent/tooling integration).

### `documentType`
- Legacy path: `offer_document`.

### `outputFormat`
- `output_format` (`pdf` / `docx`) from form radio.

### `context`
- Added by adapter:
  - `source = "generator_ui"`
  - `channel = "admin_ajax"`
  - `legacyAction = "simple_generate"`

## 2) `payload` mapping (legacy fields)

### Installation and kit
- `payload.installationType` <- `installation_type`
- `payload.kitModel` <- `kit_model`
- `payload.powerKw` <- `power_kw`

### Tank (CWU)
- `payload.tank.enabled` <- `has_cwu` (`1/0` -> bool)
- `payload.tank.capacity` <- `tank_capacity` (or `none`)
- `payload.tank.manufacturer` <- `tank_manufacturer`

### Buffer
- `payload.buffer.enabled` <- `has_buffer` (`1/0` -> bool)
- `payload.buffer.capacity` <- `buffer_capacity` (or `none`)

### Pricing
- `payload.pricing.customPriceGross` <- `custom_price`

### Floor heating fallback fields
- `payload.floor_area` <- `floor_area`
- `payload.heating_type` <- `heating_type`
- `payload.building_type` <- `building_type`
- `payload.custom_price_floor` <- `custom_price_floor`

## 3) `from-offer-dto` mapping

### Required input
- `offerDto` object (or `payload.offerDto`).

### Output normalized fields
- `installationType`: `heat_pump`
- `kitModel`: `offer.engineering.selection.pumpModel`
- `powerKw`: `offer.engineering.selection.capacity_kW`
- `bufferEnabled`: derived from `offer.engineering.buffer.{liters,setupType}`
- `bufferCapacity`: `offer.engineering.buffer.liters` (or `none`)
- `customPriceGross`: `offer.pricing.totals.gross`
- `tankCapacity`: inferred (`185-aio`/`260-aio` for AIO kits; otherwise `200`)

### Warning
- mapper appends warning with code `MAPPED_FROM_OFFER_DTO`.

## 4) Validation constraints
- `schemaVersion` required and must be `1.0`.
- `mode` in `{direct-config, from-offer-dto}`.
- `outputFormat` in `{pdf, docx}`.
- `direct-config`: `payload` object required.
- `from-offer-dto`: `offerDto` object required.

## 5) Output mapping (`OfferDocumentResponseDTO` -> legacy UI)
- Legacy UI needs:
  - `filename` <- `response.document.filename`
  - `download_url` <- `response.document.downloadUrl`
- Extended data preserved for integrations:
  - `traceId`, `document`, `meta`, `warnings`.
