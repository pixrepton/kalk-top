# Panasonic selection context

Dobor pompy: generacja (K/L/M/J) + seria (T-CAP/High Performance/EcoFlex) + typ (split/AIO/monoblok) + moc kW + fazowość.
Dobor zbiornika: objętość (150-400 l), typ (nierdzewny/emaliowany/kombinowany).
Dobor buforu: objętość (50-300 l).
Dobor komunikacji: WiFi (CZ-TAW1B), Modbus (PAW-AZAW-MBS*), KNX (PAW-AZAW-KNX*).
